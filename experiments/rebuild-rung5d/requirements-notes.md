## _buildLoops({liveItems=[], historyItems=[], agentStatusEntries=[], now=new Date(), lean=false, horizon}={}) → Loop[]
- `now` must be a Date (string/number → TypeError). Non-iterable lists throw. Cutoff `now − 30d`, row kept iff `dispatchedAt ≥ cutoff` (strict `<` drops) unless `horizon==='all'`.
- Row drops, in order: `!item||!item.id` → warn-once `pipeline-loops: skipping malformed {live|history} item` (cause `live:no-id:<id>`); no `issueIdentifier` and kind≠`autopilot` → warn-once `…:no-issueIdentifier:<id>` unless kind `wake` (silent); unparseable dispatchedAt → `console.warn('pipeline-loops: skipping {live|history} item with invalid dispatchedAt', id)` EVERY time (not warn-once).
- Abort harvest (before drops): `abort===true && abortTo` rows; non-lean from raw feedback's last terminal `[aborted]`, lean from `feedbackDigest.terminal`. Applied to target `loopId===abortTo` only if strictly later than its own terminal.
- Buckets: by `issueIdentifier`; identifier-less autopilot → own bucket `__anchor__:<loopId>` (an issue literally named `__anchor__:…` is treated as an anchor bucket → dispatchId lookup). Sort by dispatchedAt then `String(loopId).localeCompare`. Upper bound: resolvedAt (history, if parseable) else next loop's dispatchedAt else `now`.
- Agent-status match: exact `dispatchId===loopId` (latest timestamp; ties keep first; a best with null timestamp is replaced by the next entry, so all-null → LAST) overrides window `[dispatchedAt, upper]` inclusive, latest wins, ties keep first. agentState: live→queued; expired→error; cancelled→complete; else completed→complete, failed→error, blocked→waiting, else running. stage = action || promptName || 'unknown'.
- Facts: non-lean `deriveLoopFacingFacts(feedbackWithHarvestedAbort(feedback), dispatchedAt||null)`; lean `_loopFactsFromDigest(applyHarvestedAbortToDigest(digest,…))` (legacy digest w/o `answeredDecisions` → synthesized `[{decisionId: answeredDecisionId, raisedAt:null,resolvedAt:null,outcome:null}]`; `withdrawalReversed` boolean-or-undefined; no digest → empty facts + runtime.dispatchedAt).
- Lineage: `lineageId = rootItemId ?? loopId`; `lineageMetrics` = heartbeats over all fetched rows of the lineage (non-lean: parse raw feedback sorted by toEpochMs ?? 0; lean: union of digest metrics, stable sort); `lineageLastActivityMs` = max metric ts.
- Loop key order (exact): loopId, issueIdentifier, issueId, issueTitle, issueUrl, [issueSource only if != null], iteration, kind, sessionId, sessionGroupId, followUpTo, maxTasks(??null), promptName, [promptText only non-lean], dispatchedAt (raw value, may be Date/number), takenAt/resolvedAt (history only), dispatchedBy, target, repo, feedback (lean → [], else SAME array ref as item.feedback), terminalStatus, terminalCompletedAt, wakeMarker, waitingMessage, decision, decisionCase, answeredDecisionId, answeredDecisions, withdrawal, withdrawalReversed (may be undefined), source, historyStatus, bookkeeping, agentAction…agentTokenLabel, agentState, stage, telemetry, toolPeak (lean only, else null), lineageId, lineageMetrics, lineageLastActivityMs.

## _buildSessions(loops=[], {issueGraph=null, now=new Date()}={}) → Session[] (desc dispatchedAt, tie sessionId)
- Pass 1 per `kind:'autopilot'` loop: explicit `sessionId` workers + inference (seed/desc/ancestors, in `[dispatchedAt, completedAt||now]`, never other autopilots or other-session rows). Orphan sessionId groups → anchorless. 2.5a stamped `sessionGroupId` followers (session target, unclaimed, no sessionId, has followUpTo): records.get / LIN-1393 straddle merge / seed at group root / aged-out coalesce. 2.5b legacy chain-walk (cycle → null). 3: unclaimed cli/web non-autopilot loops standalone.
