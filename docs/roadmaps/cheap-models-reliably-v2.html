Cheap models, reliably — now prove it

The build is done. The account model, correct project-key billing, and reusable per-task presets all shipped — so routing Opus to research & review and cheaper models to everything else is now mechanically possible. 01

What “reliably” has to mean

A proving-phase roadmap needs a finish line you can actually check. These four are the acceptance tests — the goal is reached when all four hold, on real work, not a demo.

A A cheap model finishes a real task, unattended

An implementation ticket runs end-to-end on a cheaper model with no babysitting, and lands correct.

proven by: Harden + a live run

B You can see what it cost

Token spend, wall-clock, and the full transcript are visible per run — so “cheaper” is a measured fact, not a hope.

proven by: Instrument (LIN-1287)

C The smart model catches the cheap one

When a cheap model goes wrong, the stepper flags or corrects it before the work is trusted — supervision actually works.

proven by: Supervise (LIN-1269 / 1236)

D An unattended run survives a hiccup

A session wobble (logout, stall, dropped follow-up) doesn't wedge or silently lose the run. No known unattended-run bugs open.

proven by: Harden (LIN-1373 / 1355 / 1358 …)
