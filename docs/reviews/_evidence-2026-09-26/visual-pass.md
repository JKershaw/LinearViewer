## Shared observations (referenced by ID in the table)

**Visual-only findings** (not visible in the research JSON):

- **V1: dark theme: unthemed action buttons and links are unreadable.** Bare `.action-btn` (`public/common-actions.css:11`) sets no `color`, so a `<button>` keeps the UA's black text. It renders `rgb(0,0,0)` on the `rgb(34,36,40)` dark card, at **1.35:1**. Affected controls: Dispatch **Workspace Halt Pause / Stop / Resume**, "load Autopilot", "load Autopilot · stepped", "continue until stopped", Settings provider "make active" and "refresh / test", and Proxy event-log prev/next. `a.settings-action` has **no CSS rule at all**, so it renders UA link blue `rgb(0,0,238)` at **1.65:1** in dark. That covers 12 Settings links and Dispatch "create a preset →". In light they are legible, but the links are UA-blue and underlined, unlike every other app link. Evidence: `gap-contrast-sweep.json` (`settings--dark`, `dispatch--dark`, `proxy--dark`), `settings-dark-*.fp.png`, `dispatch-dark-*.fp.png`, `dispatch-settled-dark-*.fp.png`. Duplicate search (`dark mode contrast`, `action-btn`, `dark theme button`, `theme-dark`, `unreadable dark`) found **no existing ticket**. LIN-2251 (Done) is the same class on a different element (the escalation-KPIs `<select>`).
- **V2: error/consent family: UA-default controls survive outside the token system.** On workspace-not-found, the workspace link is `rgb(0,0,238)`: **1.89:1 in dark**, with its list bullet stranded at the far left and no gap before the button. On the Jira API-token form (a credential entry form), all three inputs are UA Arial 13.33px with a 2px inset border and **white in dark**, laid out inline with their labels. At 390 the labels and fields wrap independently of each other, and the `id.atlassian.com` link is 1.89:1 in dark. The GitHub Projects and Jira site pickers use a UA `<select>` that is white in dark. This is the LIN-2251 class recurring. Evidence: `gap-extra-probe.json`, and `err-workspace-notfound-*`, `jira-link-form-*`, `gh-projects-picker-*` and `jira-site-picker-*` `.fp.png`.
- **V3: archive provenance sign-offs are 2.94:1.** They render `rgb(139,147,160)` on `rgb(250,249,246)` at 12px mono, measured identical on archives 1, 4, 5 and 7 (`gap-extra-probe.json`). The same `--faint: #8b93a0` token is declared in archives 1, 2, 4, 5 and 7 (source). Archives 3 and 6 were not measured. This is the sign-off that D7-refined relies on as "the colophon". It fails AA on at least four public pages.
- **V4: prose set in oversized mono.** Dispatch `.guide-halt-note` is 16px JetBrains Mono, larger than its section title (`gap-contrast-sweep.json` fonts). Settings `.model-workspace-note` is 16px mono. The Scan-due disclaimers and the effort-readout explainer are mono prose. All break CLAUDE.md's "mono for machine facts, sans for human prose" split.
- **V5:** Settings toggle pills collapse into stacked "●/on" squares whenever the description beside them is long. That happens on 10 rows, so one control ends up with two shapes.
- **V6:** Settings experimental-link labels are raw camelCase flag keys ("taskChat:", "flightCompanion:", "shipBiscuit:"), placed directly under human-labelled toggles.
- **V7:** internal ticket IDs and doc paths appear in user-facing copy. Examples: Dispatch "(pending LIN-2995)", effort-readout "LIN-2566 §5" and "LIN-2567", escalation-KPIs "docs/escalation-philosophy.md §7".
- **V8:** on the Workspace Halt section, **Stop** is visually identical to Pause and Resume (chromeless text, no distinct treatment). It is the LIN-2400 class (irreversible action looks like its benign siblings) on a new surface.
- **V9:** the inline nav strip shows a **different subset of the flag-gated views on different pages**. *Corrected in impl beat 2:* beat 1 wrote "even though DOM order is the same", which is wrong. `navFoot.navLinks` shows the flag-gated links in a **different DOM order per page**: Observation starts at passage planner, Swim at live console, Ship's Biscuit at flight companion. - **V10:** at 390 the `harbour.cat` wordmark is absent on every app page, and the workspace name truncates ("Test Wo…", "Local W…") with free space beside it.
- **V11: Ship opens illegible.** Default fit zoom is 45% / 41% at 1400 and 15% at 390, which puts node text at roughly 3–5px. Cold `/ship` is pixel-identical in media-dark and light, so it does not honour `prefers-color-scheme`. Authenticated Ship uses a full-bleed 32px gutter, where every other page uses the centred column. This compounds D8: a cold visitor gets no heading and no readable text.

- **V13:** in the upstream-error diagnostic box, wrapped "Reason" values fall back to column 0 instead of hanging in the value column.
