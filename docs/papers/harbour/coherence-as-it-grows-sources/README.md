# Literature records behind coherence-as-it-grows.md

Three in-session subagents gathered these on 2026-10-08, each briefed on topics, not conclusions. Every entry says how the source was read (full text, abstract, or second-hand). The paper's own source list is the checked subset; these are the working records, kept so a review or an essay can start from them.
