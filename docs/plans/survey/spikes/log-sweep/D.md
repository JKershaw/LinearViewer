## Lessons

- **[lesson]** How the size setting shipped. The operator turned a conversational answer into a product mechanism in a brief. The Surveys made it concrete, the size call made it a requirement, and Harbour built it faithfully. Every check reads from the same altitude as the brief, so none could see that the feature itself was the mistake. John's words: "makes zero sense for someone who doesn't know specifics of how Harbour works … technically it's correct, but it's also obviously wrong and a mistake"; "Please don't … there's a much easier way"; "Please stop taking actions which compound mistakes." The remedy: when something isn't working, put the person's words on a ticket and let the loop run; never hand-steer a running session. D6 later: "the setting we removed wasn't wrong per se, just unusable". `log.md:3060–3077`, `log.md:3234`. *Partly captured in journey.md:58 and 0-ledger row 83* (the size setting as a failure, settings parked). The chain, the quotes and the don't-hand-steer rule are missing.
- **[lesson]** Instruction versus structure, measured. Prompt wording alone did not make review judge against the ask (LIN-4085 replay, 12 runs). Review catches a cut that was named and misses one that wasn't, whatever the wording, so the lever is upstream where the cut happens. Across the seal, named cuts and the size record, wording got most of the way and structure did the rest. `log.md:2860–2862`, `log.md:2890`, `log.md:2964`. *Partly captured in journey.md:50* (code keeps the books). The measured finding is missing.
- **[lesson]** Scope written by an agent drifts into how, just as hand-written scope did: the size records turned into plans, with 7 of 9 carrying how. Scope with file paths in it gets copied straight into the next brief. The parrot catches how only when it's asked to look for how specifically, not just for drift from John's words. `log.md:2923`, `log.md:2948`, `log.md:3015`, `log.md:3098`. *Missing.*
