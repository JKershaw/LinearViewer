7. Index of what else is known
  lesson-60 lesson: A page script's second request keeps the poll's discipline: coalesce every reason into one fetch per window, and stop when the poll stops (hidden tab, 401, revoked link). `createTimelineRefresher` (`public/task-page.js`, LIN-4405) is the pattern; a running chip changes the poll's track about once a minute, so "fetch when it changes" alone repeats. Done reads once more first (`finish`): the poll that says done carries the last change, and stopping drops it.
  lesson-63 lesson: Shared leaves: a shared module is a leaf (it imports nothing and names no browser or Node global, `tests/unit/shared-modules.test.js`), served only through the explicit `SHARED_MODULES` allow-list in `lib/vendor-assets.js`, one route per file under the served /lib/ namespace, never by directory (a lib file not on the list is a 404). A page imports one with a relative specifier that starts with ../lib/ (quoted in the code).
