7. Index of what else is known
  lesson-60 lesson: A page script's second request keeps the poll's discipline: coalesce every reason into one fetch per window, and stop when the poll stops (hidden tab, 401, revoked link). `createTimelineRefresher` (`public/task-page.js`, LIN-4405) is the pattern; a running chip changes the poll's track about once a minute, so "fetch when it changes" alone repeats. Done reads once more first (`finish`): the poll that says done carries the last change, and stopping drops it.
  lesson-63 lesson: Shared leaves: a shared module is a leaf (it imports nothing and names no browser or Node global, `tests/unit/shared-modules.test.js`), served only through the explicit `SHARED_MODULES` allow-list in `lib/vendor-assets.js`, one route per file under the served /lib/ namespace, never by directory (a lib file not on the list is a 404). A page imports one with a relative specifier that starts with ../lib/ (quoted in the code). That resolves to the same file in the browser and in Node only because `public/` is served at the URL root and stays flat, with no nested .js files (`tests/unit/front-end-import-layout.test.js`). Do not move `public/` under a prefix or add a subdirectory.
  lesson-66 lesson: A `{ module }` entry's place in a renderer's script list means nothing: a module runs after every classic script, wherever it is listed. A bridge reader is safe because of when it reads the global, not where the shim sits.
  lesson-67 lesson: A converted page is tested by plain `import` over the fake DOM (`tests/unit/helpers/import-world.js`), not by `loadWorld`. Each import is a fresh module instance, and the world puts every global back when it is restored. The classic-loader census (`tests/unit/classic-loader-census.test.js`) is a ratchet on the suites that still load classic scripts: it may only fall. A suite that runs a classic file through `runClassic` counts, except `public/chart-helpers.js` and `public/close-out.js`, the two IIFE siblings a module page may read.
