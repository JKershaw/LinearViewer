Message:

```text
Fix stale dvh after mobile keyboard dismisses

Sizing body with 100dvh leaves a blank strip under the input row on
Safari and some Chromium states: after the virtual keyboard retracts,
the browser doesn't always recompute the dvh value, so the page stays
sized to "viewport minus keyboard" while the actual visible viewport is
full-height again.

Drive the body height from visualViewport.height via a CSS custom
property. visualViewport fires a resize event on every keyboard
show/hide, URL-bar show/hide, and orientation change, so the layout
tracks the actually-visible area reliably.

https://claude.ai/code/session_0162VbmbQuRzSmC4CN6Witsq
```

+function updateAppHeight() {
+  const h = window.visualViewport?.height ?? window.innerHeight;
