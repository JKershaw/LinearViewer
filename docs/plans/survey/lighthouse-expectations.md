## The expectations

1. **Lists with no end grow.** Any list that runs add to and nothing removes from (findings, notes, waiting work) grows from run to run. A list the checker covers does not. *(Picture §2, out of the task; §6, places with no end.)*
2. **An editable source gets corrected in place.** If runs edit the task table directly, corrections land on the entry itself, and Harbour's pattern of corrections piling beside a frozen source does not appear. If entries are frozen or append-only, the pattern appears. *(Picture §2, up; §6, frozen sources.)*
3. **Retellings drift.** Where a run restates an earlier run's state (a summary, a status line, a count), figures and claims drift between retellings. *(Picture §2, retold.)*
4. **Checks out of reach are carried as text.** A check that needs John's own accounts or systems appears as "not run" or "not verified", and is repeated rather than done. *(Picture §2, out of reach.)*
5. **Standing text makes the choices, from one rule set.** `AGENTS.md` and the run instructions make choices John would otherwise make: what to do next, and how much. With one rule set and one agent per run, rules do not collide the way scoping's and the autopilot's did. *(Picture §3.)*
6. **Nothing leaks across, unless runs overlap.** With scheduled runs by one agent at a time, there is no sideways leak. If runs do overlap, the same blindness to each other appears. *(Picture §2, across.)*
7. **A task carries little.** A run's starting reading is a few files (the instructions, the table, the recent history), far less than a Harbour stage's ticket, parent plan and thread. *(Picture §5.)*
8. **Information moved out of Harbour.** For the Harbour-driven work of 25–26 Sep, most of the information lived in Harbour's records (dispatch feedback, completion records) rather than in the repository. After 26 Sep it lives in the repository. *(Picture §1, Harbour's stores. Partly told by the summary.)*
9. **Writing nobody checks.** Whatever runs write that the checker does not cover is never read by anyone else before it is relied on. *(Picture §2, written where no one checks it.)*
