# The tally of broad options: moved to the area notes

This file collected the Survey's broad options, by the thing they would change, with the
tickets that named them. Since LIN-4371 (8 Nov) its open rows live in the area notes,
`docs/areas/`, each filed under the area of the file it is about. Read
`docs/areas/README.md` for the format and the one-home rule: a leftover is either a filed
follow-up (scheduled) or a note entry (known, not scheduled), never both.

- **Open rows about Harbour's code** are waiting entries in `docs/areas/<slug>.md`, citing
  the tickets that named them as "Survey tally".
- **Open rows about simple-dispatcher's code** (settings as one described list, an
  acknowledged outbox for runner posts, a flag registry with retirement, the size of
  `opencode-runner.js`, mutant anchors checked by `npm test`, one process-group
  termination helper, a system test importing Harbour's internals, and that repository's
  half of the transcript fold and the resumable-session contract) go to
  simple-dispatcher's own `docs/areas/` (LIN-4372).
- **Rows that had landed** (the cost code's home, one Stop sequence, the shared harness
  for the heavy test tier, loading as part of the cost read, a record of which contract
  each test pins, and the Home-wide live repaint, LIN-4243) and the tally's working
  rules stay in git history: read this file at `eeda7e44` for the table as it stood.

The rest of `docs/plans/survey/` is frozen research record and is not maintained.
